# SRZ MO Čadca

Homepage redesign for Slovenský rybársky zväz – Miestna organizácia Čadca.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Plain CSS with design tokens (no Tailwind / UI kits)
- Content in `content/site.ts`

See `OPEN_ITEMS.md` for missing facts and stub pages.
